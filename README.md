# TC3002B

Coursework for TC3002B (Advanced Computer Science Applications Development).

The focus is developing computational tools using Artificial Intelligence, Compilers, and Quantitative Methods to detect copyright infringements in digital media.

## Structure

- `m1-research`: Research
- `m2-ai`: Artificial Intelligence
- `m3-compilers`: Compilers
- `m4-quant`: Quantitative Methods
- `reto`: Course challenge
